04 — CTAs

Estados de Ação

A lógica de exibição dos botões depende de workout.status, workout.canStartNow e do tipo de esporte. Cada estado resulta em um conjunto diferente de botões.

Estado A · Hoje
canStartNow == true
status == .scheduled
→ Iniciar (grad) + Concluir (secondary) + Pular (secondary)
Estado B · Futuro
canStartNow == false
status == .scheduled
→ Concluir (grad) + Pular (secondary)
Estado C · Concluído
Nenhum outro botão para status .done
status == .done || .partial
sportType == .running
→ Adicionar dados (secondary)
Estado Vazio — Sem Blocos e Sem Segmentos
Nenhum bloco definido para este treino
noBlocksCard · workout.blocks.isEmpty && workout.segments == nil
