# Tokens de Cor

CSS variables em `root`:

```css
:root {
  --primary-400: #0ea5e9;
  --primary-500: #0284c7;
  --primary-neon: #00d4ff;
  --secondary-500: #a855f7;
  --secondary-neon: #bf40ff;
  --background-dark: #0a0a0f;
  --surface-card: #1a1a24;
  --text-primary: #f9fafb;
  --text-secondary: #d1d5db;
  --success: #10b981;
  --warning: #f59e0b;
  --error: #ef4444;
  --info: #3b82f6;
}
```

## Uso

- **Primária**: buttons, links, accents
- **Secundária**: highlights, modals
- **Neon**: glows, borders, effects
- **Text**: primary = body, secondary = hints
