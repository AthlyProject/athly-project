# Gradientes e Glows

## Gradientes principais

**Primary**: azul → roxo
```css
background: linear-gradient(to right, #0ea5e9, #a855f7);
```

**Neon**: cyan → magenta
```css
background: linear-gradient(to right, #00d4ff, #bf40ff);
```

## Glows (box-shadow)

**Neon glow**:
```css
box-shadow: 0 0 20px #00d4ff;
```

**Secondary glow**:
```css
box-shadow: 0 0 15px #bf40ff;
```
