# Athly Technical Vault

Vault técnico para documentação do projeto **Athly** — Personal trainer de corrida com IA.

Estruturado em 3 camadas principais:
- **Backend** (NestJS + Prisma + PostgreSQL + Gemini AI)
- **Frontend** (React + TypeScript + TailwindCSS)
- **iOS** (SwiftUI + MVVM + HealthKit)
